# 카드뉴스 에이전트

사용자와 함께 카드뉴스를 만드는 웹 앱입니다. 주제를 넣으면 최근 소식을 조사해 후보를 보여 주고, 사용자가 고른 소식으로 심층 조사 → 편집 방향 → 스토리보드 → 그림 → 글자 배치 → 수정 → 최종 승인 → PNG·ZIP 내보내기까지 진행합니다. 단계마다 사용자가 확인하고 고릅니다.

> 현재 상태(2026-10-25): 전체 흐름이 실제 엔진(**Claude CLI**)으로 동작합니다. 그림은 agy(Antigravity) 또는 Claude CLI(SVG)로 그리고, 승인할 때 고릅니다. 출처는 공식 발표·주요 언론을 우선하고 등급을 표시합니다([SOURCES.md](SOURCES.md)). 결정과 이유는 [DECISIONS.md](DECISIONS.md), 작업 과정은 [context.md](context.md), API는 [API_SPEC.md](API_SPEC.md)에 있습니다.

## 처음 실행하기 (Windows 기준)

### 1. 준비물 확인 (처음 한 번)
PowerShell을 열고(시작 메뉴에서 "PowerShell" 검색) 아래 명령을 입력합니다.

```bash
node -v
```

`v24.`로 시작하는 숫자가 나오면 됩니다. "인식되지 않습니다"라고 나오거나 숫자가 24보다 작으면 https://nodejs.org 에서 LTS 버전을 설치한 뒤 PowerShell을 새로 엽니다.

### 2. 프로젝트 폴더에서 터미널 열기
**이 README.md가 들어 있는 폴더**(`card-news-workflow-kit`)에서 명령을 입력해야 합니다. 둘 중 편한 방법을 쓰세요.

- **방법 A (탐색기):** 파일 탐색기로 `card-news-workflow-kit` 폴더를 연 뒤, 위쪽 주소창을 클릭하고 `powershell`이라고 입력해 Enter를 누릅니다. 그 폴더에서 PowerShell 창이 열립니다.
- **방법 B (명령):** PowerShell에서 폴더로 이동합니다. 이 PC 기준 경로는 아래와 같습니다. 다른 곳에 풀었다면 그 경로로 바꾸세요.

```bash
cd "C:\Users\cheon\OneDrive\바탕 화면\AI Agent\card-news-workflow-kit"
```

맞는 폴더인지는 프롬프트(`PS ...>`)의 경로가 `card-news-workflow-kit`로 끝나는지로 확인합니다.

### 3. 필요한 부품 설치 (처음 한 번)

```bash
npm install
```

`node_modules` 폴더가 생기면 끝입니다. 다시 설치할 필요는 없습니다.

### 4. 서버 켜기
목적에 맞게 **둘 중 하나**를 입력합니다.

**로그인 없이 화면 흐름만 보기 (모의 데이터)** — 처음이라면 이것부터 해 보세요.

```bash
npm run start:mock
```

**실제 웹 검색으로 실행하기** — Claude Code CLI 로그인이 필요합니다(아래 "Claude 로그인" 참고).

```bash
npm start
```

아래와 같은 줄이 나오면 서버가 켜진 것입니다. **이 PowerShell 창은 닫지 말고 그대로 두세요.** 창이 열려 있는 동안만 서버가 동작합니다.

```
카드뉴스 에이전트: http://127.0.0.1:8765  (엔진: mock, 모의 데이터)
```

### 5. 브라우저에서 열기
Chrome이나 Edge 주소창에 아래 주소를 입력합니다.

**http://127.0.0.1:8765**

모의 데이터로 실행했다면 화면 맨 위에 노란 띠("모의 엔진으로 실행 중입니다…")가 보이고, 모든 후보에 "모의" 꼬리표가 붙습니다. 실제 검색 결과가 아닙니다.

### 6. 사용 순서
1. **주제 입력:** 주제(예: `AI 최신소식`)와 기간(최근 7일 또는 30일)을 고르고 "조사 시작"을 누릅니다.
2. **조사 진행:** 진행 메시지가 보입니다. 실제 검색은 몇 분 걸릴 수 있습니다. 멈추려면 "작업 취소"를 누릅니다.
3. **후보 선택:** 후보 카드에서 제목, 날짜(확인 못 하면 "미확인"), 원문 링크, 선택할 가치, 불확실성을 보고 1~3개를 체크한 뒤 아래쪽 "선택 저장 후 심층 조사"를 누릅니다.
4. **질문 답변:** 파란 테두리의 질문 카드가 나오면 선택지를 하나 고르거나 직접 입력하고 "답변 제출"을 누릅니다. "추천" 표시는 참고용이며, 직접 골라야 답으로 저장됩니다.
5. **결과 확인:** 조사 기록(확인된 사실, 발표 주체의 주장, 한계, 상충 내용)과 편집 방향(독자, 형식 비교와 추천, 카드 구성, 근거가 달린 후킹 문구)이 나옵니다.

중간에 새로고침하거나 창을 닫았다가 다시 열어도 진행 상태가 그대로 남아 있습니다. 첫 화면의 "이전 프로젝트"에서 다시 열 수 있습니다.

### 7. 끄기
서버를 켠 PowerShell 창을 클릭하고 **Ctrl+C**를 누릅니다. "일괄 작업을 끝내시겠습니까 (Y/N)?"라고 물으면 `Y`를 입력하고 Enter를 누릅니다. PowerShell 창을 그냥 닫아도 서버가 꺼집니다.

다시 켤 때는 2번(폴더에서 터미널 열기)과 4번(서버 켜기)만 하면 됩니다.

### 문제가 생겼을 때
- **"포트 8765이(가) 이미 사용 중입니다":** 이미 다른 창에서 서버가 켜져 있습니다. 그 창을 찾아 Ctrl+C로 끄거나, 다른 포트로 실행하세요. 다른 포트로 켰다면 브라우저에서도 http://127.0.0.1:8766 처럼 그 포트로 엽니다.

```bash
$env:PORT=8766; npm run start:mock
```

- **"npm은 인식되지 않습니다":** Node.js가 설치되지 않았거나 설치 후 PowerShell을 새로 열지 않은 것입니다. 1번을 다시 확인하세요.
- **화면에 "Claude 로그인이 필요합니다":** 아래 "Claude 로그인"을 따라 하거나, 서버를 끄고 `npm run start:mock`으로 다시 켜서 화면 흐름만 확인하세요.
- **"서버에 연결할 수 없습니다":** 서버 창이 닫혔거나 꺼진 것입니다. 4번으로 다시 켭니다.

### Claude 로그인 (실제 검색을 쓸 때만)
아무 PowerShell 창에서나 아래 명령을 입력하고, 열리는 브라우저에서 로그인합니다. 브라우저에 코드가 나오면 PowerShell에 붙여 넣고 Enter를 누릅니다. 이 로그인은 PC 전체에 적용되므로 폴더는 상관없습니다.

```bash
claude auth login
```

## 설정 (선택)
기본값으로 충분합니다. 바꾸고 싶을 때만 PowerShell에서 `$env:이름=값; npm start` 형태로 지정합니다.

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 8765 | 서버 포트 |
| `HOST` | 127.0.0.1 | 다른 값으로 바꾸면 이 컴퓨터 밖에서도 접속할 수 있으므로 경고가 나옵니다 |
| `CARD_NEWS_ENGINE` | claude-cli | 실행 엔진. `claude-cli`(실제 검색) 또는 `mock`(모의 데이터). `npm run start:mock`은 이 값과 상관없이 mock으로 실행 |
| `CARD_NEWS_CLAUDE_MODEL` | sonnet | Claude CLI에 넘길 모델 |
| `CARD_NEWS_CLAUDE_EFFORT` | medium | Claude CLI의 effort (low, medium, high, xhigh, max) |
| `CARD_NEWS_ENGINE_TIMEOUT_MS` | 1500000 | Claude CLI 호출 하나의 시간 제한(25분, 언론사 11곳 검색 때문에 15분에서 늘림) |
| `CARD_NEWS_MOCK_SCENARIO` | normal | 모의 엔진 전용. `few`(7일 결과 3개 → 30일 확대 질문), `search_fail`(검색 실패 화면) |
| `CARD_NEWS_DATA_DIR` | data | 상태 DB와 작업 파일을 저장할 위치 |
| `CARD_NEWS_DISABLE_WEBSEARCH` | (없음) | 진단용. `1`이면 웹 검색 도구를 빼고 실행해 "검색 실패" 화면을 실제 엔진으로 확인할 수 있음 |
